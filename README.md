# 🛒 BuyBusy - Redux


## 📦 About the Project

**BuyBusy** is an e-commerce web application built as a **Coding Ninjas project** using **ReactJS**, **Redux Toolkit**, and **Firebase Realtime Database**. Users can register, browse products, add or remove items from their cart, and place orders — with all data being saved persistently in Firebase.

This project demonstrates key concepts of modern frontend development, including state management with Redux, routing with React Router, and real-time database operations with Firebase.

---

## ✨ Features

* 👤 Create and manage your user account
* 🛍️ Add or remove products from the shopping cart
* ➕➖ Adjust product quantity in the cart
* 💳 Place an order and receive a bill summary
* 🔁 Cart and order data saved in Firebase (persists between sessions)
* 🔔 Toast notifications for feedback and alerts

---

## 🛠 Tech Stack

* **React.js** – Frontend library
* **Redux Toolkit** – State management
* **React Router DOM** – Client-side routing
* **Firebase Realtime Database** – Persistent backend storage
* **React Toastify** – UI notifications
* **JavaScript (ES6+)**
* **CSS**

## ⚙️ Installation & Running the App

Follow these steps to run the project on your local machine:

1. **Clone the repository**

   ```bash
   git clone https://github.com/Kunal-0821/E-commerce-website.git
   ```
2. **Navigate to the project folder**

   ```bash
   cd BuyBusy-Redux
   ```
3. **Install dependencies**

   ```bash
   npm install
   ```
4. **Start the development server**

   ```bash
   npm start
   ```
5. **Open your browser and go to**

   ```
   http://localhost:3000/
   ```
